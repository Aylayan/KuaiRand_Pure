# 四张清洗表字段字典与取值统计

> 数据来源：KuaiRand-Pure 公开脱敏历史数据的本地清洗结果。
> 本文档只描述本项目实际读取到的字段和取值分布，不把脱敏编码解释成未公开的真实业务属性。

## 统计口径说明

- 每张表分别统计，缺失值作为一种独立状态计入次数。
- 枚举型字段列出全部取值及次数，并给出次数合计；合计应等于该表总行数。
- ID、时间戳、连续数值及高基数字段不逐项罗列，而是展示总数、缺失、唯一值、范围和最高频取值。
- 日志中的 date_clean 用于日趋势，hourmin 用于小时分布，time_ms 仅用于事件排序；三者不强制互相反推。

## 使用提醒

- random 与 standard 日志只能做同时间窗口的描述性比较，不能直接表述为A/B实验或因果结论。
- is_live_streamer_clean 的缺失表示未知哨兵值，不等于“不是直播作者”。
- play_ratio_raw 允许大于1；如需封顶指标，应另建字段并明确口径，不能覆盖原始值。
- tag 和 onehot_feat0 至 onehot_feat17 均为脱敏字段，不能解释为真实内容主题或用户隐私属性。
