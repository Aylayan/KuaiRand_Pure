# 核心指标口径

## 规模指标

| 指标 | 定义 | 适用视图 |
|---|---|---|
| 推荐记录数 | 行为事实表行数 | overall / daily / hourly / segments |
| 用户数 | `COUNT(DISTINCT user_id)` | overall / segments / comparison |
| 视频数 | `COUNT(DISTINCT video_id)` | overall / segments / comparison |
| 有效视频时长记录数 | `is_complete_play` 非空的记录数 | overall / comparison |

## 行为率指标

| 指标 | 分子 | 分母 |
|---|---|---|
| 点击率 | `is_click = 1` | 全部推荐记录 |
| 长播率 | `long_view = 1` | 全部推荐记录 |
| 完整播放率 | `is_complete_play = 1` | 视频时长有效的记录 |
| 点赞/评论/关注/转发率 | 对应行为字段为 1 | 全部推荐记录 |
| 综合互动率 | 点赞、评论、关注、转发任一发生 | 全部推荐记录 |

SQL 中的 `*_rate_pct` 已转换为 0—100 的百分数值，例如 `46.3981` 代表 `46.3981%`。Power BI 使用自定义显示格式追加 `%`，不得再次乘以 100。

## 播放质量指标

| 指标 | 口径 |
|---|---|
| 播放时长中位数 | `play_time_ms / 1000` 的中位数，单位秒 |
| 播放进度中位数 | `play_time_ms / duration_ms_clean` 的中位数，仅限时长有效记录 |
| 进度达到 100% 的比例 | `play_ratio_raw >= 1` 的记录占时长有效记录的比例 |

播放进度允许超过 100%，可能对应循环或重复播放，因此不强制封顶，也不直接视为脏数据。

## 聚合注意事项

- 总体卡片使用 `vw_metric_overall_standard`，不能从每日或分层视图重新求和比率。
- 每日趋势以 `date_clean` 为轴，一天一行；不能用每日率的简单平均代替全周期总体率。
- 用户/内容分层中的比率只能在当前分组粒度解释，不能跨分组直接 `SUM`。
- 小样本分组需要与推荐量、用户数和视频数同时展示，避免把偶然波动解释为稳定规律。
- 标准推荐与随机推荐只做同期样本描述，不使用“提升”“导致”等因果措辞。

## 推荐质量链

本项目不把“点击、长播、完播、互动”强行串成严格线性漏斗。原因是这些字段不是按交易漏斗方式记录的连续事件，且存在少量未点击但长播、完播或互动的记录。

正式展示采用“曝光层 + 点击后质量分支”：

```text
推荐曝光
└─ 点击/有效播放
   ├─ 点击后长播率
   ├─ 点击后完整播放率
   ├─ 点击后正向互动率
   └─ 点击后负反馈率
```

| 指标 | 分子 | 分母 |
|---|---|---|
| 点击后长播率 | `is_click = 1 AND long_view = 1` | `is_click = 1` |
| 点击后完整播放率 | `is_click = 1 AND is_complete_play = 1` | 点击且视频时长有效的记录 |
| 点击后正向互动率 | 点击后点赞、评论、关注、转发任一发生 | `is_click = 1` |
| 点击后负反馈率 | `is_click = 1 AND is_hate = 1` | `is_click = 1` |

曝光层指标用于评价每100次推荐带来的行为结果；点击后指标用于评价用户开始播放后的观看和互动质量，两类分母不能混用。

## 负反馈护栏

新增负反馈率作为策略护栏：

| 指标 | 分子 | 分母 |
|---|---|---|
| 负反馈率 | `is_hate = 1` | 全部推荐记录 |
| 点击后负反馈率 | `is_click = 1 AND is_hate = 1` | `is_click = 1` |

推荐策略不能只追求点击、长播或完播。如果主指标改善但负反馈率同时上升，应进一步检查内容刺激性、重复曝光或用户体验损失。

## 共同用户配对验证

标准推荐和随机推荐共有 25,877 名用户。为降低高曝光用户对总体结果的过度影响，先按“推荐方式 × 用户”计算个人行为率，再对同一用户的“标准推荐率 - 随机推荐率”进行等权汇总。完整播放率只对视频时长有效记录计算，因此该指标实际可配对用户为 25,846 名。

配对分析包含：

- 用户等权平均差异（百分点）；
- 用户差异的中位数；
- 差异为正、为负和为零的用户占比；
- 以用户为重采样单位的 95% Bootstrap 置信区间。

该置信区间描述共同用户样本中平均差异的不确定性，不把重复曝光当作完全独立样本；但它仍不能替代随机A/B实验。

## 分层稳定性门槛

用户和内容分层保留全部分组，但只有同时满足以下条件的分组才用于提出普遍策略：

- 标准推荐和随机推荐各不少于 1,000 条记录；
- 标准推荐和随机推荐各不少于 100 名用户。

未达到门槛的分组可以作为异常线索展示，但必须明确标记“小样本，不形成稳定结论”。

## 单一构成变量校正

为检查总体差异是否主要来自样本构成，分别按用户活跃度、注册时长、视频时长、视频类型和画面方向进行直接标准化：

1. 计算标准推荐与随机推荐在各分组内的行为率；
2. 使用两种推荐方式合并后的分组占比作为共同权重；
3. 分别计算共同构成下的标准推荐率和随机推荐率；
4. 比较校正前后差值。

该方法只能控制一个已经观测到的分层变量，不能消除曝光位置、推荐时机、未公开特征或推荐机制带来的混杂。

## 因果解释边界

- 共同用户很多，不等于用户被随机分配到实验组；
- 两种推荐方式只有 136 个共同“用户—视频”组合，不适合包装成同用户同内容实验；
- 可以使用“同期样本中表现更高”“差异在共同用户口径下仍然存在”；
- 不使用“标准推荐导致指标提升”“证明推荐算法有效”等表述；
- 策略是否产生真实增量，需通过用户级随机分流A/B实验验证。
